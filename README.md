# Customer Churn Analysis

## Project Overview
Customer Churn Analysis is a data analytics project that analyzes customer data to understand customer churn patterns and help businesses improve customer retention.

## Objectives
- Analyze customer churn and retention.
- Clean and preprocess customer data.
- Perform Exploratory Data Analysis (EDA).
- Visualize important customer insights.
- Explore machine learning techniques for churn prediction.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Machine Learning
- Decision Tree
- Power BI
- Oracle SQL
- Visual Studio Code

## Project Workflow
1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Power BI Dashboard Creation
6. Decision Tree Model Exploration

## Dataset Summary
- Total Customers: 900
- Non-Churned Customers: 750
- Churned Customers: 150
- Overall Churn Rate: 16.67%

## Key Insights
- Analyzed the distribution of churned and non-churned customers.
- Used visualizations to understand customer patterns.
- Created Power BI KPI cards and charts to present customer churn information.
- Explored Decision Tree modelling for customer churn prediction.

## Learning Outcomes
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Data visualization
- Power BI dashboard development
- Basic machine learning concepts

## Conclusion
This project helped me understand how data analytics and machine learning can be applied to customer churn analysis. The insights can help businesses identify churn patterns and develop strategies to improve customer retention.
